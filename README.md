# Stack Attack (Bounce Back)

Haven game jam entry, theme **BOUNCE BACK**. Godot 4.7, web export.

Pancakes slide in from the side, tap to drop them on the tower. Perfect = bonus, a bit off = the
overhang gets cut, very off = lose a life and the tower wobbles. Miss completely and the pancake
bounces away. 3 lives, 5 perfects in a row = bounce back (+1 life). Coins unlock outfits.

## Run
Open the folder in Godot 4.7 and press F5. Tap / click / SPACE to drop.

## Art
`assets/` -> characters, blocks, ui, backgrounds (see ASSETS.md for names). Missing art shows placeholders.
